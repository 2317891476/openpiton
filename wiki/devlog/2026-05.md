## 2026-05-27 -- Root cause of Versal Debug Hub failure identified (Build 25 vs Build 26)

- **Root Cause Confirmed**: The failure to communicate with the post-synthesis ILA (Build 25) is due to a missing AXI connection and NoC address mapping in the PL fabric between the Debug Hub (`axi_dbg_hub`) and the PMC Master (`PMC_AXI_NOC0`).
- **Build 25 Issue**: Using post-synthesis `create_debug_core` / `.xdc` insertion results in Vivado creating the `axi_dbg_hub` block in the PL fabric but leaving its AXI slave interface floating/unmapped. The generated LTX shows it mapped to `0x44a00000` with no `available_addresses` master configuration, making it unreachable via the PMC debug route.
- **Build 26 Fix**: Instantiating the ILA (`axis_ila_0`) directly inside the Block Design (`openpiton_top.bd`) allows IP Integrator to synthesize and route the Debug Hub within the same context as the PMC and AXI NoC. This properly wires the Debug Hub to `ps_wizard_0/PMC_AXI_NOC0`, mapping it to the correct address `0x3ffc0000000`. Runtime verification confirms that Labtools can successfully refresh the device, enumerate `hw_ila_1`, and capture waveforms.
